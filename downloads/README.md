## 下载后怎么用

1. 在你常用的AI聊天中上传选好的完整TXT。
2. 让AI先读取完整内容，说明未能读取的部分。
3. 输入自己的任务、已有素材和不能改的地方。

可以直接发送：

```text
请先读取我上传的完整创作方法，说明未能读取或缺失的部分。
我的任务：……
已有素材：……
不能改的地方：……
先给我：选题建议／结构／旁白／定向修改（选一项）。
```

上传文件是向本次聊天提供方法资料，不等于在设备中安装Skill，也不保证永久记忆。手机上若下载不方便，直接用[全文复制或编号分段](../copy/README.md)。[各平台详细步骤与限制](../docs/使用指南.md)

## TXT、Markdown和Skill ZIP，选哪个

- **完整TXT：** 普通聊天用户的优先选择，上传后让AI读取。
- **完整Markdown（MD）：** 和TXT内容完全相同；你当前客户端接受MD时可选。
- **单Skill ZIP：** 供具有Skill导入入口或文件操作能力的工具安装，包含完整目录。普通聊天用户不必选它。[安装说明](../docs/安装Skill.md)
