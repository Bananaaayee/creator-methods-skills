# 三套方法横向对照

这三套工具迁移的是研究中可观察的创作决策。名称用于说明研究来源，不是要求用户扮演某个人。下面的分工来自本轮及既有研究；实测能否体现这些差异，另见评测报告，不凭说明文字认定能力已提升。

| 决策 | 何同学 | 小鹿 Lawrence | 影视飓风 |
|---|---|---|---|
| 切入点 | 从具体处境找到有不同可能答案、能取得材料的问题；偏爱与个人记录也可成立 | 从真实观察、关系、旅程或使用摩擦积累主题，避免先写抽象感悟 | 先认清最终要承担的解释、判断、交付或理解责任，再看现场能否预设 |
| 行动与材料 | 让比较单位、验收与实际用户任务对应；区分客观结果、感受和解释 | 用实际相处、具体细节、信息与自身体验连接主题；器材操作成本可能改变记录机会 | 展示能力、条件测试、机制论证、真实样片分别负责，不能互相代证 |
| 结构 | 真实改变下一步的尝试链有价值；Q&A、并列清单、多任务及普通结尾也可用 | 行程顺序、人物互动和思考可以衔接，但不替人物写内心；不把零散风景自动升格主题 | 可控讲述可先拟窄承诺；开放现场先观察记录，再从真实事件选主线；娱乐与感官作品也能完成任务 |
| 文字 | 个人动机连接信息与验收，未达原目标可以诚实结束 | 旁白承担必要信息与有限个人理解，环境声/画面承担可感知细节；漂亮话不能补事实 | 信息接具体后果，结论强度接证据条件；不为高密度删掉限制 |
| 不宜强套 | 假失败、必有反转、大规模实验、每题人生升华 | 统一抒情口吻、所有段落留白、从字幕推断镜头/音乐规律 | 每题都做宏大测试、每段都认知反转、所有技术视频同一种脚本 |

## 选哪套

“我不知道这个现象值不值得拍、如何验证”可从何同学开始；“我有经历和人物，但找不到素材里的主题”可从小鹿开始；“我有技术参数或多种影像证据，不知道能论证到哪里”可从影视飓风开始。三者可处理重叠题材，题材标签本身不决定方法。需要混用时先说清最终交付，只借确实需要的决策工具，不把三套流程全部叠加。

以一台小相机为例：一套方法可能先选用户可验证的具体问题；一套先看设备是否让实际记录更容易、操作代价转移到了哪里；一套分开厂商陈述、条件测试、样片和购买判断。这是观察角度，不要求每个任务交出三种不同故事。停水通知、严格局部修改和事实边界等任务，答案相近是合理的；一般诚实规则不构成独有风格。

## 共同边界

- 原始字幕能支持文字内容和作者自述，不能单独验收真实画质、无剪辑连续性、配乐、声音、节奏、观众效果或私下研发过程。
- 作者的因果解释、团队自述和个人体验保留来源归属；单次表现不推出稳定能力，代理指标不代最终结果，成片顺序不代发现顺序。
- 引用作品时核对身份、覆盖层和可迁移条件；索引有题名不等于有完整分析。没有材料时应承认未知，仍可给一般方法建议。
- 不复制原句、长文、人格、固定结构或可识别表演。用户事实、立场、口吻、已接受段落和明确限制优先。

本轮没有建立独立冻结的小鹿文字风格模型，也没有完成三位创作者的系统视听研究。三套方法是否出现决策同质化，以同任务实际输出的横向复核为准；后续研究应围绕分歧和失败，而不是补更多相似的案例卡。

## 本轮输出实际呈现的差异

在6道共同任务的匿名语义复核中，C01的选择与验证动作存在会改变拍摄的区别；C04、L01的相近较多来自题目约束与共同证据责任。C03的部分完整剪辑表、H01的分组方案、M01的视觉论证链则被判为高重合。此处“高重合”是评审对当前答案的判断，不证明复制或人格风格混淆，也没有证明三套方法在重叠任务中稳定可分。灰度测试等任务的合理设计本来就可能收敛，现有短案例的区分能力也有限。完整依据见[交叉检查原始结果](../tests/results/cross-style.json)。
