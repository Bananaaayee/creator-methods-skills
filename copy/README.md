## 怎么复制

1. 打开所选页面，先复制短启动说明发给AI。
2. 再复制完整方法正文。文字太长时，按编号逐段发送；每段已经包含加载说明，整段复制即可。
3. 发完全部内容后，再发送自己的创作任务、已有素材和不能改的地方。

**短启动说明不是完整Skill。** 只发一句启动词，不能声称已经加载整套方法；浏览网页也不等于在设备中安装Skill。

手机上若整页文字不便选择，优先使用该创作者的“编号分段”入口；若当前页面提供代码块复制按钮，也可直接复制对应整块。

分段不能扩充模型总上下文。没有收到全部方法、只读到部分附件或已经遗忘早期内容时，必须说明现在是有限上下文版本。不要为了“用上某位创作者”补事实、改写你的经历或复制原文。

能上传文件时，[直接下载一份完整TXT](../downloads/README.md)通常更省操作。无需安装代码工具。
