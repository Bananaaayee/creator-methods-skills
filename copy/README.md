# 复制完整方法，在你常用的AI里使用

适合豆包、DeepSeek或任何不方便上传文件的聊天窗口。无需安装代码工具。

1. 选择 **[影视飓风](MediaStorm/README.md)**、**[何同学](Hetongxue/README.md)** 或 **[小鹿 Lawrence](Lawrence/README.md)**。
2. 先复制该页的短启动说明，再复制完整方法正文，最后发送你的创作任务。**短说明不是完整Skill。**
3. 平台不接受长消息时，按页面顺序复制带编号的分段；每段已经包含加载说明，整段复制即可。

分段不能扩充模型总上下文。没有收到全部方法、只读到部分附件或已经遗忘早期内容时，必须说明现在是有限上下文版本。不要为了“用上某位创作者”补事实、改写你的经历或复制原文。
