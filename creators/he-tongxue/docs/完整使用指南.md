# 何同学 Creator Skill V1.3.0｜使用指南

本工具帮助你决定一期内容要回答什么、真实材料能支持什么，以及怎样让行动和结果进入结构。它是独立研究工具，与作者及团队无合作或背书关系。

## 1. 安装与两种使用方式

**模块化**：把整个 `skill/` 目录复制到支持技能目录的环境，建议目录名 `he-tongxue-creator`，入口 `SKILL.md`。只安装入口文件会丢失方法和作品索引，必须保留全部相对路径。

**单文件**：加载 `dist/he-tongxue-creator-skill-v1.3.0-portable.md`，明确要求按其方法处理任务。可上传到支持Markdown附件的ChatGPT项目或对话；是否持续遵守仍受平台指令和检索机制影响。没有读到文件时不能声称已加载。

已有任务时直接开始，不强制显示长介绍。可以检查：

```text
用一句话说清这期要完成的任务、你真实读到的材料和仍未知的部分，然后完成我的请求。
```

## 2. 现在有什么，就从那里开始

|你现在有什么|优先给什么|无需做什么|
|---|---|---|
|模糊对象|可回答问题、为何值得、最低成本检验|先写全文或批量标题|
|确定的判断题|命题、材料、反例、比较条件|先保证有反转|
|正在做实验/装置|变量与版本链、验收与异常|预设失败次数和成功结果|
|已拍完的真实素材|材料→证据→结论→段落|在不能补拍时追加虚构素材|
|已有文案|定位具体问题，交付指定范围修订|每次重做研究和选题|
|反馈后的第二次修改|沿用接受部分，撤回被否决推断|悄悄恢复旧主线|

不要为了运行Skill而填写全部字段。关键信息缺失时，它应先给条件分支或在现有事实范围内推进，只追问会改变当前结果的信息。

## 3. 七条任务路线与进入条件

|路线|核心责任|有用材料|不适用情况|
|---|---|---|---|
|真实使用判断|能力是否改变真实任务|收益、摩擦、替代方案与个人条件|没试用却下购买结论|
|把问题测清楚|让方法回答经验命题|变量、对照、测量、比较单位、异常|把偏爱或理念伪装成实验|
|把东西做出来|版本解决真实约束|原型、失败原因、改变量、验收|补造三次失败|
|为真实的人解决问题|由外部用户和现场定义任务|需求、否决/改写权、安全与真人完整任务|假想用户或纯功能展示|
|追到今天的原因|用来源和反例解释后果|决策、事实、机制、反例与今日参照|将动机猜测或时序直接写成因果|
|成片背后发生了什么|解释已发布作品的生产因果|正片、生产版本、代价与更正|只有日常花絮|
|用旧档案重看自己|旧材料约束今日认识|同期档案、当时所知、后来结果|只有后见之明的回忆|

七条路线不是七种固定叙事模板。全片可以是单任务、多单元或混合。现场快报、开箱、比赛、Q&A是外层格式；多个问题可以并列，不强求唯一主题或个人升华。

## 4. 选题：对象怎样成为问题

可以说：

```text
我想拍旧笔记本，只有两天和自己这一台。
先给一个现在就能回答、对观众有用的问题，说明什么相反结果也能成片。
```

Skill应检查谁会关心、答案会改变什么、哪些材料区分答案、资源能做到哪里。它可以建议缩题或明确个人观察，不会声称何同学本人每次照四步产生灵感。

## 5. 实验：先说清怎样判断

可以说：

```text
我想比较两个App的检索体验。先检查公平比较单位，
分别记客观找到率、完成时间和我自己的使用感受，别预设赢家。
```

实验先建立观众能理解的合同：比什么、测什么、什么差异回答原问。时长、次数、循环、里程和有效工作量不能混用。客观指标与主观感觉冲突时保留两条结果，不能靠个人解释替代测量。样本与耗时不是可靠性的替代物。需要预测时再让观众猜；不要求所有科普都设计实验或类比道具。

## 6. 版本与结果：做出来不一定解决原问

有意义的失败链是“原方案→实际失败→新约束/变量→新方案”。纯调试、笑点和蒙太奇不用包装成发现。没有失败也能完成作品。

检查原目标是否实现，和是否做出了别的有价值成品。键盘可调力度不等于已经缓解疼痛；设备能动不等于用户能独自准备、使用、收纳，更不等于长期可靠。结尾要结算实际完成了什么。

## 7. 已有素材：让材料反推结构

可以说：

```text
不能补拍。只用我给的日志、样片和采访原话做结构。
每段标明它能回答什么；证据不够就缩小结论。
```

先把事实、体验、待验证主张、气氛和缺失材料分开，再排段落。观众必须知道的局部结果及时释放；总判断等证据够再给。没有最终画面时，不补写质量、胜负、人物反应，也不把字幕缺失解释成留白。

## 8. 方法与文字分别控制

默认保持你的表达，只清理必要歧义和衔接。可以说“稍微加强文字表达”或“明显加强”；调用的是具体入口、约束推进、技术到体验的翻译、观点层级和有边界的结果，不复制口癖、标题、梗或单篇结构。

“结构不动，只改文字”会锁定主问题、章节顺序、段落职责、事实、证据、结论和行动设计。必须改结构才能解决时，Skill应指出问题并给最小替代，不偷改整篇。

个人材料可解释为什么在意、真实使用感受或结果怎样被重估，但不能替你编写心理转变；没有第二层意义就正常结束。

## 9. 改稿与第二次反馈

```text
第二段太像评测广告。只删掉没有证据的推荐，保留我的犹豫，其他段落不动。
```

Skill应给该段修订和短理由；无需重新解释全部路线。你再次说“还是太重，只留观察，不要结论”时，它应撤回旧推断，沿用已接受的事实与文字，不恢复被你否决的主线。

直接要求“写90秒旁白”“写完整脚本”“重写全文”，就是授权相应范围，无需额外口令。说“先别写全文”会停止全文。授权不能填造未发生的实验、采访或结果；缺事实可以标占位或给条件稿。

## 10. 具体作品参考

可以指定准确题名、作品ID或唯一片段。Skill会检索包内77个作品 Capsule，只调用本轮需要的任务、行动、成片转段、结论边界与迁移条件。标题不唯一时请你选一次，不猜。

- 读到作品级条目：具体说明能借什么、条件是否存在、哪部分不能迁移。
- 只有基础身份或未读到条目：降到路线级，不补写内部结构。
- 未研究：说明后继续用总体方法，或分析你当场提供的材料；临时分析不算既有研究。
- Partial：只用可靠片段。能参考某作方法不等于能参考其文字，仍需Text支持和你的请求。

本包的Capsule是研究者对成片的功能归纳，不是作者内心或真实研发顺序。若你要知道“他当时为什么决定”，没有公开材料就保持未知。

## 11. 研究范围与回退

继承资料：77张旧Research Card，65篇进入旧原文验证，32篇Text Deep，5篇Partial。本轮首轮复核12篇，后续反例与高风险审查累计复核37篇（含定向风险段），其余40篇仅全体机器筛查；不能把继承数量说成此次全量逐字验证。新增证据的相对文件名、原始行号与SHA见 `skill/references/evidence-index.md`。

当前研究重点是任务、材料、证据、结构和文字功能。镜头、剪辑、音乐、音效、语速与表演可按一般创作能力继续帮助，但不冒称何同学规律。一次演示、单用户成功、工程样机和时间先后都只有相应结论范围。

进阶协作可查看路线、材料、结构锁和输出偏好；“回到普通协作”只隐藏面板，不清空事实。理解偏航时直接纠正，或用恢复卡：

```text
我在做：
已经确定：
真实已有：
还没发生：
不要改变：
现在只需要：
```

## 12. 版本与评价

V1.3.0保留成熟研究，新增决策接口、按需索引和来源限定，详见CHANGELOG。旧版V1.2的Reference缺载荷问题已由V1.2.1修复，本轮没有把旧故障当作新发现。使用效果与退步以统一真实对照测试为准；静态安装检查不代表创作行为全部通过。
