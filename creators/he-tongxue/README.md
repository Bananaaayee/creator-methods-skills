# 何同学 Creator Skill V1.3.0

把题材变成能回答的问题，让真实行动、材料和结果决定作品怎样推进。基于何同学公开作品研究整理的独立工具，与作者及团队无授权、合作或背书关系。

## 开始使用

- **模块化安装**：将 `skill/` 整个目录作为一个技能目录安装，建议目录名 `he-tongxue-creator`。入口为 `skill/SKILL.md`，相对引用全部在目录内。
- **便携使用**：加载 `dist/he-tongxue-creator-skill-v1.3.0-portable.md`，并明确要求按其中方法完成当前任务。可作为支持Markdown附件的ChatGPT项目/对话资料使用；平台是否持续读取文件取决于其文件检索和指令机制。
- 已有任务时直接交付，不再强制播放旧版长 Startup。全文请求本身授权相应范围，不需另说确认口令。

可以直接说：

```text
我只有一台旧相机和周末两天，想拍“便宜设备够不够用”。
先帮我把题目缩成能由这些条件回答的问题，别写全文。
```

```text
下面是实拍日志，不能补拍。只用现有结果给一个6分钟结构；
不要把一次成功写成可靠，也不要改我最后仍然犹豫的态度。
```

```text
第二段太空，只修改这段，保持章节顺序、事实和我的口语。
```

## 擅长与边界

- 适合：任务化选题、实验/制作过程、产品实际价值判断、真实用户项目、历史或档案材料组织、定向改稿。
- 保留七条任务路线、单任务/多单元/混合入口，及77篇作品级方法参考；信息清单和个人记录不被硬改为实验片。
- 侧重任务、证据、结构和文字功能。镜头、剪辑、配乐、真实语速、平台绩效及作者私下决策，没有被当前研究系统验证。
- 不复制口癖、长原句或某一作品整套结构，不编造经历、测试、失败、用户反馈或视觉结果。

方法和文字是两个开关。默认保留你的声音；说“稍微加强文字表达”才使用对应文字机制。说“结构不动，只改文字”会锁定结构。“进入进阶协作”可查看路线、材料和边界；日常无需操作面板。

## V1.3.0 的实际变化

1. 将77个作品 Capsule 从核心模块移至按需索引；成熟参考载荷仍完整保留。
2. 增加可回答性检查、观众可理解的判定合同、公平比较单位、客观/主观/个人解释分轨、已有素材反推结构和定向修订接口。
3. 校正两条多单元作品路由，限定人物动机推断与成片/研发顺序，避免把研究者解释当作者内心事实。
4. 缩短启动，按自然语言任务识别写稿范围，减少与当前任务无关的固定流程。

改动依据和反例见 [重要规则证据索引](skill/references/evidence-index.md)。变化细目见 [CHANGELOG.md](CHANGELOG.md)，限制见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)，完整说明见 [使用指南](docs/完整使用指南.md)。行为提升以总交付中的实际对照评测为准，不以版本号或新增规则数量判断。
