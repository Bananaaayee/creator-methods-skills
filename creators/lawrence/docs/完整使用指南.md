# 小鹿 Lawrence Creator Skill V1.3.0 使用指南

## 这套工具做什么

它帮助你判断作品当前要回答的问题、哪些材料有资格支持结论，以及下一步该观察、采访、测试、写作还是只改一段。它从小鹿作品研究中学习方法，保留你的立场与表达，不要求你写成小鹿本人。

旧版已完成的六路线与83篇作品参考继续有效，本版增加材料到主题、器材到记录机会、旁白分工和局部反馈的入口。它不是从零更换研究模型。

## 两种交付形式

**单文件便携版：**加载dist中的V1.3.0 Markdown，然后在对话中明确说“请使用这套Skill协助当前任务”。附件被保存不保证已成为持续行为指令；在新会话说明使用意图，并保留必要项目事实。

**模块化版：**使用完整skill文件夹，入口SKILL.md带有名称和用途。支持Skill安装的环境按照自身安装方式读取；不要只复制入口而漏掉references。六模块按01→06完整加载也可独立使用。普通任务不必读取83条参考；指定作品时再调用。单文件版已包含全部运行内容，模块版无需本机语料库。

## 给多少信息才够

不用先填一张长表。直接说现在要的成果、已有材料、哪些是计划、不能改什么；器材/行程等必要条件随任务补充。信息不全时工具应给有限方案、条件或清楚占位，只追问会改变路线的缺口。

- 选题：“我总觉得拍了很多附近的店，却没有一条片。先从我的笔记中找一个有材料的题。”
- 结构：“我已经拍完，不能补拍。按我给的素材编号组织3分钟结构，不要预设关系改变。”
- 旁白：“只用下列事实，给我一版90秒旁白。没发生的事用占位。”这已授权90秒稿，无需再说固定口令。
- 局部修改：“结构不动，只把第二段写得更直白，保留我最后一句。”工具应只改有关段落。

## 题材不是任务

同一次旅行可以是本次体验判断、地方问题、人物关系或只是轻量假期；同一台产品可以承担用户适用性、方法教学或项目工具。六条路线是研究者的组织方式，不是作者官方分类：

| 当前要回答 | 优先材料 | 停在哪里 |
|---|---|---|
| 对象对谁适用 | 用户、使用场景、时长、摩擦、对照 | 有条件的推荐与限制 |
| 观众怎么做/选 | 目标、原则、动作/标准、错误与取舍 | 可解释可尝试的方法；不宣称观众已经学会 |
| 此次体验如何 | 当次预算、天气、交通、体力、现场变化 | 本次条件下的判断 |
| 地方背后的公共问题 | 来源、时间线、现场与有位置的口述 | 来源允许的有限回答 |
| 项目完成了什么 | 依赖、版本、故障、替代、验收 | 实际交付与代价 |
| 人物/关系/记忆 | 物件、共同经历、当事人声音、分歧 | 有归属的新理解，不保证和解 |

多单元问答、轻松体验和结果笑点可以不建立唯一强主题；不必强迫每段承担证据链或升华。

## 从观察走到主题

先找到材料中的可复述细节，再问它带来什么真实疑问或关系。比如你有“同一位店主每次提醒我别把面吃坨”这类笔记，它可以支持熟客交往；没有其他材料时不必立刻说成整座城市的共同体。候选主题应回到具体行动/原话，材料不足就缩小结论或给下一次观察。

这是一种运行建议。研究可观察到XL-026的附近地点与来往、XL-010的照片与家人口述怎样支持主题，却不能据成片倒推作者脑中真实先后。教程或已有明确问题可直接按任务展开。

## 让人物、行程与思考连得上

转段用真实关联：同一物件、未答问题、行动成本、当事人的一句话或下一步选择。人物只是向导或证人时，不自动变主角。本人未说、材料未证明的内心，不由漂亮旁白补齐。

失败改变方案、结论或理解才承担转折；没有反转也能保留实际失败。不同结果各自结算，不用“收获意义”取消实际损失。

## 器材片别只列功能，也别统一轻便至上

在旅行/纪实场景，可检查器材让什么瞬间被留下、什么被错过：携带、开机、调平、收音、被摄者反应、挑素材和后期由谁承担。用实际记录、样片和反馈支持判断。专业画质或商业交付可能优先其他标准；短测不能写成长测，团队反馈不能写成控制实验。

## 旁白、现场话与留白

每段先确定必须知道的事由什么承担：画面可见动作、人物原话、旁白补条件/背景，或图表给来源。工具看不到画面时应承认未知；待拍建议不冒充已有镜头。关键时间、因果、范围和来源不能因“有氛围”被删。

XL-031明确说过为歌词删去MV的部分对白字幕；它是单篇操作自述，也有小屏易读等相反责任。不能据此规定每段空镜秒数、全片少旁白，或声称实际效果已验证。未提供声画时，只给可验证的分配方案。

## 指定某一期作品

说出作品标题、ID或唯一标题片段即可。工具应先确认匹配，再调用该期不可替换的行动、证据、变化或边界，并检查你的资源和材料是否存在。83条载荷保留了V1.2.1 Reference Repair成果。

- 作品级参考：可以借任务、推进、行动和边界，不复制标题/文案/章节。
- 只有基础覆盖或无法读载荷：只做总体/路线建议，不补细节。
- 未研究：说明一次后继续用总体方法，或分析你提供的材料；不假装有既有研究。

5篇PARTIAL不补写缺口；VAL只表示进入过历史验证池，不等于全片各维度都已验证。更换或取消参考后，旧作品建议不继续暗中影响项目。

## 反馈后的第二轮

反馈先定位改变维度：事实、主副线、结构、信息量或语气。保留未受影响的材料与认可段落，直接给修订。若局部变化必须连动上下文，说明依赖与最小改动；不能每次“更自然”都重做选题，也不能补一段从未发生的经历。

用户说“别升华”可以停在结果或收窄为个人感受；说“更有生活感”可以换为已有的动作、物件和原话。用户样稿里的犹豫、幽默与判断优先，不抛光成别人替你确定的道理。

## 研究边界与恢复

未建立独立小鹿文字口吻模型；字幕不能独立证明实际构图、调色、配乐、表演、剪辑节奏、画质或观众理解。这些仍可按一般能力帮助，但不能冒充已验证创作者规律。外部历史/生态/产品参数等事实另行核验。

偏航时直接纠正即可；必要时用恢复卡：

```text
我在做：
已经确定/不能改：
真实已有/已经发生：
还没发生，不能编：
我已认可的段落/原句：
现在只需要：
```

空项保持未知，不自动恢复AI旧推断。版本变化、已知问题、证据定位与测试结果分别见随包相应文件。本指南不将文件可读或安装结构校验等同于创作质量通过。
