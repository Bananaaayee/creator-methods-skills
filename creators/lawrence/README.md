# 小鹿 Lawrence Creator Skill V1.3.0

基于83篇作品研究的独立创作协作工具。先判断这期对什么负责，再让具体经历、现场条件和人物声音决定材料与结构。支持旅行、人物、纪实、器材真实使用、教程与局部改稿；保留用户的表达。

非官方工具，与小鹿 Lawrence 本人及团队无授权、合作或背书关系。

## 开始使用

- **便携使用：**加载 `dist/lawrence-creator-skill-v1.3.0-portable.md`，并明确要求“请使用这套Skill，帮我……”。上传文件本身不等于已安装或已启用。
- **模块化安装：**将完整 `skill/` 文件夹复制到支持Skill的环境，并按该环境要求命名为 `lawrence-creator`；入口是 `skill/SKILL.md`。保留六模块及references，不只复制入口。
- **分模块维护：**六模块按01→06顺序可完整加载；入口提供按任务读取规则。指定某期作品时才需加载83篇参考载荷。

例如：“我拍了半天社区修鞋摊，只有录音和四段画面。请先找素材能支持的主题，不预设人物的一生，也别写全文。”

## 本次具体变化

1. 保留六种做片责任、主副线/并行、轻量停止与83条作品级参考，避免丢失V1.2.1的Reference Repair成果。
2. 新增从具体观察到有限主题的检查；区分成片关联与未知的构思过程。
3. 把器材操作成本接到真实记录机会，保留画质、焦段与后期成本的不同权重。
4. 补旁白/现场话/画面分工；将删字幕留白限定为单篇自述策略，未建立全频道视听定律。
5. 缩短首次介绍；自然语言写稿请求即可授权相应范围；用户反馈只触发有关部分修订。
6. 83条载荷移至按需参考文件，取消重复基础目录；单文件版仍包含全部必需内容。

## 能力边界

没有独立量化的小鹿文字口吻模型，不提供文风强度，也不模仿本人。字幕不足以验证镜头、调色、音乐、表演与实际剪辑效果；需要时可按一般创作能力协助，并说明来源。单次使用不是普遍性能实验，短相遇不是深层人物理解。标准产品说明或轻量体验不必套旅行/人物/升华结构。
