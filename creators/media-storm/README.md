# 影视飓风 CreatorSkill V1.22.0

把技术问题、产品材料或真实现场组织成能被证据支持的作品，并保留你的表达。独立非官方项目。

## 开始使用

- **模块化**：安装 `skill/` 整个文件夹，目录名使用 `media-storm-creator`；入口是 `skill/SKILL.md`。
- **ChatGPT便携**：上传 `dist/media-storm-creator-skill-v1.22.0-portable.md`，直接提出任务。不同平台的上下文和文件读取能力会影响表现，不能保证自动注册为插件。
- **使用示例**：“我只有一台相机和周末两天。请从这些真实测试结果设计结构，不补实验。”“这段结构不动，保留口气，只把参数讲清楚。”

## 实际改了什么

在 V1.21.1 已有的七类任务、440 基础作品索引、72 个作品 Capsule 上增补：

1. 用现场是否可预设来决定先定题还是从真实事件成题；
2. 分开展示、条件测试、机制论证、真实样片的证据责任；
3. 以用户决定和生产链路筛选测试，避免每件产品都做全面深评；
4. 只改文字时跳过重路由，用户反馈后按影响范围修订；
5. 去掉固定长欢迎词，作品库按需加载，仍完整保留引用能力。

新建议有原文范围与反例，见 `skill/references/evidence-vnext.md`；它们是本研究的操作化转译，不是推测作者心里的固定流程。

## 擅长与边界

适合技术解释、条件化产品判断、项目实现、从材料到结构、对真实结果的保守表达。也可处理人物和旅行，但不会强行加入实验或购买结论。

不提供真实测试结果，不代替拍摄，不从字幕推断精确剪辑、配乐、语速或视觉效果。不复制创作者台词与人格；缺信息时缩小主张或给计划。原始字幕仍保留本地，不在本包。

使用细节见 [完整使用指南](docs/完整使用指南.md)，变化见 [CHANGELOG](CHANGELOG.md)，限制见 [KNOWN_ISSUES](KNOWN_ISSUES.md)。旧版本保留在原交付目录，不被覆盖。
