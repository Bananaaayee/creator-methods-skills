# 实际评测与回归报告

本轮得到的结论有限而明确：作品级参考有可核对的事实纠正，模块化入口与便携文件可用；通用创作题没有证明新版稳定、全面胜过成熟旧版，也没有证明三套方法在重叠题材中稳定可分。不能用版本号、格式通过或更多研究文字替代这个结论。

## 实际条件

2026-10-25，使用已登录的Codex CLI `0.164.0-alpha.11.1`；模型固定`gpt-6.1-sol`，推理档`high`，每次新临时目录、新临时会话，统一JSON输出且禁止工具/联网。完整方法文件作为输入，旧版与候选均不截断。无Skill只不附加方法，其余任务与输出条件相同。启动命令、方法指纹、时长、token用量和退出码有实际记录。

先冻结11个初始案例，再用各条件C05的真实输出重放用户反馈C09，共12项；三作者都测试同一组方向、结构、素材、产品、旁白、局部修订、缺信息、非适用情境及三道领域专项。首轮共7条件、84份答案（无Skill12份由三个比较组共用）。每条件按4/4/3题分批，题目相互独立但同批共享上下文；不能冒称逐题独立随机实验。反馈是显式重放真实对话，不是ChatGPT产品内持久会话测试。

七维各0—4分，总分28：切中任务、方法适配、可执行性、事实诚实、模板克制、用户表达与范围、可观察约束。版本和名称隐藏、每题固定随机打乱A/B/C，裁判不看Skill、审计或预期改法。文风和说明仍可能泄露条件，因此是身份遮蔽而非严格双盲。

评分器出现过可复核错误：把隐藏名称标记当成正文未填占位，又把实际附加方法语境中的“所附研究”当成不存在背景。该初轮评分不用于比较；原始评分保留，修正说明后重新运行。未因新版本分数低而删除答案、改标签或只挑最高一轮。

## 方法区分、模块化与安装

6道同任务的匿名语义复核中，C03、H01、M01的部分核心方案被判高重合；C01有会改变拍摄的选择差异，C04/L01的收敛更多来自题目约束。合理方案相同不自动构成混淆，但本轮不能声称三套工具在重叠任务中稳定可分。原始语义依据保留在`results/cross-style.json`。

独立前向检验只从各自SKILL入口按路由读文件，完成同一修旧物委托及“只改旁白末句”反馈。三份首轮为80汉字，结构和反馈前缀均保留；修改后何同学78字，另两份80字，如实记录。未遇到不存在的外部依赖。此检验是定性使用记录，不作为同条件盲测分数。

三套均通过标准Skill格式校验、临时安装、拒绝覆盖、相对引用、构建指纹检查。没有自动安装进用户设置，也没有做ChatGPT网页上传或全平台自动发现验收。便携版包含全部运行模块与参考，内部链接指向嵌入章节；模块化按需加载可减少默认核心文件范围，但本轮没有测得速度／费用收益，单文件体积反而有所增加。

## 结果文件与适用结论

`results/`保存各轮原始答案、原始与修正后的评分、解盲映射、客观范围／字数检查、运行元数据和模块化记录。完整方法输入、事件日志、旧包快照和原始语料在本地研究资产中保留，不混入日常Release。

可以发布的结论是：有证据的摘要校正、完整参考载荷保留、可用的模块化与便携形式，以及有限案例中可复现的边界改进。没有明显改善的是通用写作均分、精确字数稳定性及重叠任务的方法可分性。下一步优先真实项目长对话、原始视听证据和真人编辑成本；继续机械增加相似Research Cards的价值较低。
