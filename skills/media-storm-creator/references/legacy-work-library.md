## Internal Reference Work Coverage Index

本区只供 Runtime。字段：`作品ID<TAB>准确标题<TAB>WorkflowHint<TAB>Mixed<TAB>Coverage`。

WorkflowHint 使用 `1–7`，如 `1+2` 表示主候选 + 次候选；`U` 表示既有研究仍不足以可靠落到七类之一。Mixed 的 `1` 表示地图或深研认为存在第二责任/边界混合。Coverage 为 `M`（MAP）、`D`（DEEP）、`V`（VERIFIED）、`T`（TEXT）的组合；每条必有 M。

调用权限：

- 仅 M：只可参考大方向/候选责任；不可声称掌握详细结构或该期文字机制。
- 有 D：可参考任务、行动、证据、推进、结果和结构边界。
- 有 V：可调用其独立验证所支持的相关命题/边界；V 不自动等于完整作品结构研究。
- 有 T：可调用该期已研究支持的文本功能观察；不等于逐句模仿。
- 任意组合都不支持仅凭字幕确认镜头、剪辑、音乐、声音或画质。
