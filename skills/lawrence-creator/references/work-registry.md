# 小鹿 Lawrence｜83篇作品参考载荷



本 Registry 是压缩后的作品级运行载荷，不是 Research Card、作品摘要或仿写模板。普通用户不需要看到字段名；Resolver 只调用与当前任务相关的部分。`RC+VAL` 表示该作品进入 07B 验证池，但不等于整篇所有维度均已验证；`PARTIAL` 必须保留实际缺口。当前没有独立 Text Expression Research，因此所有 `text_note` 均为 `NONE`。

解析时优先使用精确标题，再用 ID，再用标点/空格归一化标题或唯一标题片段。每个条目的 `route_hint` 只做候选路由；真正建议必须调用作品自己的任务、行动、推进、变化、边界和迁移条件。



这些任务、推进、变化与迁移字段是对成片的研究解释；不据此断言作者在拍摄前已有同样规划或内心决定。具体使用与案例只支持当次条件，不等于独立实验或外部事实认证。
