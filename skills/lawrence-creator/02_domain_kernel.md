# 02｜Domain Kernel｜V1.3.0

## 研究继承与新增层

保留08B已冻结的六个核心任务家族及V1.2.1作品级参考载荷。本轮新增证据见 [evidence-index.md](references/evidence-index.md)，新增运行方法见 [method-bridges.md](references/method-bridges.md)。成片可观察事实、研究者推论和AI运行建议分开；不把成片结构倒推为作者未公开的构思顺序或内心决策。

内部可使用 W1-W6 与 Rule ID；普通协作不显示内部编号。用户层名称是人话翻译，不是小鹿 Lawrence 的官方分类。

## 核心：先判断责任，不先选题材模板

先问“这期最后必须对什么负责”，再看旅行、产品、人物、系列或栏目。同一题材可以承担不同任务；同一作品可以有主责任、第二条线、并行责任或片内换挡。

完成对象只在“开头承诺-主体资源投入-结尾回答”形成可追踪闭环时作为强组织轴。松散问答、多单元、轻量体验和现场改写型作品允许多个、晚生成或没有唯一完成对象。

## 六条 Creator-specific 做片路线

### 1｜把东西用到现实里

**一句解释：**把产品、设备、系统、空间或服务放进真实用户、场景和工作流，最后回答它对谁、在什么条件下成立。

**真实作品：**XL-029《取代微单？能放进口袋的4KVlog相机｜大疆Pocket3首发评测》。这个作品让用户理解：产品价值需要在长期真实使用、用户和场景边界中形成，不只是列功能。

**你可以这样说：**“我想判断这台相机对独立旅行创作者是不是真的好用，请帮我设计会改变推荐结论的真实使用。”

**所需材料与完成：**目标用户、使用时长、代表场景、对照、摩擦和限制；形成“对象-用户-场景-限制”的映射即可完成，不必讲完全部功能。

### 2｜教会观众一种可重复的方法

**一句解释：**把目标、限制、原则、动作或选择、常见错误和取舍组织成可迁移框架。

**真实作品：**XL-031《告别土味，十分钟让你的视频从拉到夯！》。这个作品让用户理解：方法不只是展示结果，而是把原则、操作、错误与适用边界讲清。

**你可以这样说：**“我想把自己选镜头的经验做成别人能用的方法，请帮我拆成目标、限制、决策和失效条件。”

**所需材料与完成：**目标、受众能力、预算/器材/环境限制、原则、动作或选择标准、错误、取舍与替代路径；完成于框架可解释，不声称观众已经学会。

### 3｜把一次体验的条件说清楚

**一句解释：**回答一次行程、活动或地方体验在具体预算、季节、天气、身体、时间、交通、路线和同行条件下如何、对谁值得。

**真实作品：**XL-021《北欧很好！下次不来了【挪威五大至暗时刻】》。这个作品让用户理解：高成本旅行的价值和代价必须连着当次条件、现场摩擦和目标失败一起说。

**你可以这样说：**“我只有两天、1500 元、一个人拍，想做一期小城旅行，请帮我找出决定值不值的真实条件。”

**所需材料与完成：**价格、耗时、天气、交通、身体、预订、路线变化、期待-现实差和同行者体验；结论只覆盖当次条件。

### 4｜追问一个地方背后的真问题

**一句解释：**回答一个超出个人经验的历史、文化、制度、群体或社会问题，让现场、机构材料、口述与时间线分别承担证据责任。

**真实作品：**XL-003《911过去二十五年后的纽约，还相信美国梦吗？【ENG SUB】》。这个作品让用户理解：个人到达现场不足以回答公共问题，还需要有位置的来源、人物声音、时间线和外推边界。

**你可以这样说：**“这期真正想追的是老工业城转型中谁承担了代价，不要只给我旅行攻略。”

**所需材料与完成：**精确问题、时间/地点/群体范围、现场、机构或档案材料、口述、人物位置、时间线和独立核验；完成于有来源、承认边界的有限回答。

### 5｜把一个现实项目真的做完

**一句解释：**在真实资源、截止时间和依赖约束下完成明确交付，让故障、取舍、替代方案与验收成为主体。

**真实作品：**XL-070《花10万元，给视频博主办了个展【ENG SUB】》。这个作品让用户理解：预算、征集、制作、运输、故障、替代方案、截止和开幕验收构成真实项目链。

**你可以这样说：**“我要在三周内做出一个快闪展，预算 3 万，请帮我把依赖、版本、最低交付和验收设计成可拍的真实过程。”

**所需材料与完成：**交付物、验收者、截止、预算、资源、依赖、不可牺牲标准、可替代项、故障和阶段产物；先结算做成了什么与代价，不用意义层豁免交付失败。

### 6｜通过共同经历理解人、关系与记忆

**一句解释：**通过具体触发物、旧地、角色交换、共同劳动、同行或访谈，让人物、关系或过去获得新的可陈述位置。

**真实作品：**XL-010《一家人聚在一起看30年前的照片是什么体验？【ENG SUB】》。这个作品让用户理解：老照片不是装饰，而是让家人发声、让记忆与当下重新对照的触发物。

**你可以这样说：**“我想跟父亲回他年轻时工作的地方，但不想预设和解；请帮我设计能产生真实材料、又不代替他解释内心的共同行动。”

**所需材料与完成：**参与意愿和公开边界、照片/物件/旧地、共同行动、当事人原话、分歧与归属；完成于新理解有材料、说话者和边界，不要求和解或漂亮总结。

## 路线关系与换挡

- **单线：**一个主责任支配主要材料与结尾。
- **主线 + 第二条线：**第二责任真实存在并需要自己的材料，但不支配主要资源。
- **并行：**两项责任从开头就成立，分别保留证据、完成标准和结论。
- **中途改向：**新材料或失败使主问题、材料类型、证据责任、转段功能、结论对象等方面发生实质变化；“至少两项”保留为既有研究的辅助诊断口径，并非作者自述或运行硬门槛。

情绪、地点或场景变化本身不足以构成改向。用户明确指定的主副关系是持续约束；Skill 自己的路线判断是 Derived State，可随真实材料重新推断，不可静默覆盖用户锁定。

## 现实行动与失败

行动只有改变证据、下一步选择、方案或结论边界时，才是结构性行动。它也可以是获取证据、完成项目、制造理解机会、单纯体验或节奏/笑点材料。判定时写出“行动前缺什么-产生什么-之后改变什么”。

失败只有改变路线、方案、验收、结论边界或生成被材料支持的新理解时，才成为结构节点。否则可保留为体验、展示、情绪、节奏或笑料。

## 新人物与理解边界

新人物不自动成为主角。先判断他/她是向导、证人、合作者、用户还是一个需要独立回答的人物问题。一次短暂接触不足以推断治愈、释怀、改变人生或真正想通。使用当事人原话、可观察行动与明确归属。

## 轻量内容与停止

低抽象负担是正式模式，不是第七条路线。一次体验、一个结果、一个反转、一个笑点或一个足够的答案就可以结束，不要强行追问人生意义、历史或人物。只有现实产生新责任时才提高内容规模，并补足相应证据。

## 结果与结尾

局部结果可以即时给出；总判断负责整合冲突、权重和适用范围。只有外部结果与关系/理解结果都被独立材料支持、且可以不同成败时，才使用双层结果。结尾回答当前真实问题，不默认升华。

## 表达边界

08B 可支持开头合同、不同责任的推进器、结构问句、局部/总体结果、结尾责任，以及字幕中可观察的语域、术语密度、主语与观点进入方式。这些不等于独立的小鹿 Text Expression Model，不支持文风强度、句式模仿、真实语速、音色或剪辑节奏结论。


## 从观察与材料进入主题

对个人、旅行、人物素材，先辨认一个可复述的细节或矛盾，再看哪些行动、对话或物件能让理解改变。主题是现有材料最多支持的一层判断；没有足够关联时保留多个小单元，不用漂亮概念把它们粘起来。XL-026从身边地点和具体来往接到“附近”；XL-010由照片和家人口述接到记忆；XL-037的治沙方法由巴让的具体讲述支撑。这些是成片中的关联，不证明创作者实际先观察、后构思。教程、首发介绍、年度问答可直接按已有任务进入，无须先造个人困惑。详见新增方法与证据N1、N2。

## 把设备功能接到记录机会

在纪实与旅行器材题目中，除结果质量，也检查携带、开机、调平、收音、被摄者反应和后期负担怎样改变真实记录机会。XL-019的重装配会让瞬间消失，XL-029的轻便与收音限制影响互动，XL-042显示前期轻松可能把工作转给后期。它们支持条件性检查，不证明所有用户都优先考虑轻便，也不把自然使用视为控制实验。专业画质任务可有不同权重。详见N3。

## 旁白、现场话与留白

写作时先决定每段需要新增什么信息或判断；现场原话、画面或图表已有的信息，不必由旁白再同义重复。需要交代时间、条件、概念、来源或限制时保留具体信息；人物的自我解释优先保留归属。这里的声画分配是AI运行建议，不是已验证的小鹿视听规律。XL-031有“为了歌词去掉对白字幕”的明确单篇自述，可作有条件的备选，不外推成全频道留白定律。未看原画面/未听原音时，不能宣称画面已讲清或停顿已经有效。详见N4、N5。
