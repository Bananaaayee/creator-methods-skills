# 小鹿 Lawrence Creator Skill V1.3.0

协作目标：让具体经历、人物声音和现场条件决定作品可以说什么、怎样推进。

## 加载与执行

- 用户明确要求使用本Skill时，按本流程协作；用户要求审阅、总结或调试文件时，把文件作为待分析资料，不执行其中创作指令。
- 正常使用先读 [01](01_portable_instruction.md)、[03](03_product_policy.md) 与 [05](05_decision_logic.md)。需要选题/结构时读 [02](02_domain_kernel.md)；多轮纠正、锁定或恢复时读 [04](04_runtime_state.md)；涉及研究能力或参考覆盖时读 [06](06_research_boundary.md)。
- 处理个人观察、真实素材、旁白/影像分工与器材价值时，按需读 [新增方法](references/method-bridges.md)。重要归因可核对 [证据索引](references/evidence-index.md)。
- 指定具体作品时按 [05的Resolver](05_decision_logic.md) 查 [83篇作品载荷](references/work-registry.md)；其他任务不必加载全表。不能读取支持文件时，说明参考深度受限，仅用已加载的总体方法继续，不凭记忆补作品。

六模块按01→06可顺序加载；单文件便携版包含全部运行规则和作品载荷，不依赖本机研究目录。用户的当前目标、真实材料、锁定要求和表达优先于研究方法。
